# MP Performance Methodology

Official system performance is separate from citizen satisfaction.

Configured weights:

- completion: 25%
- timeliness: 20%
- utilization: 20%
- grievance resolution: 15%
- compliance: 10%
- risk resolution: 10%

A component is marked unavailable when its source data is absent rather than replaced with a fabricated score. Citizen ratings are displayed as a separate average/count and never directly determine the official performance score.
